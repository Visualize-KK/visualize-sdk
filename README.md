# Visualize iOS SDK

Body scanning for your app: capture, on-device measurement, results screens.

## Install

Xcode → File → Add Package Dependencies → paste this repo's URL → pick the
latest version.

## Requirements

| | |
|---|---|
| iOS | 17+ |
| Device | Face ID iPhone (TrueDepth) for real scans; Simulator runs a stub |

## Keys

Get your publishable key and API docs from the developer portal. The secret
key stays on your server — it mints the session tokens your app hands the
SDK.
