# Visualize samples

Two runnable samples that together make one working integration.

| Sample | What it is |
|--------|-----------|
| [`ios-quickstart`](ios-quickstart) | The smallest iOS app: a scan button that opens the full member experience |
| [`backend-quickstart`](backend-quickstart) | A one-file Node server: mint sessions, receive signed webhooks, forward deletions |

Run the backend first, then the app — the app fetches its session tokens
from the backend, exactly as a production integration does.

Full documentation is on the developer portal under Docs.
